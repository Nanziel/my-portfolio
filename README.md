# 🌐 My Personal Blog Portfolio

![Project Status](https://img.shields.io/badge/Status-Active-brightgreen)
![Course](https://img.shields.io/badge/Course-CSD_34203-blue)

A responsive personal blog website developed as a final project for **Special Topics in Software Development**. This project demonstrates the implementation of fundamental web technologies and version control management using Git.

Designed for students and developers to showcase their portfolio, thoughts, and contact information in a clean, minimalist interface.

---

## 🚀 Key Features

### 📱 Fully Responsive Design
* Automatically adapts to Desktop, Tablet, and Mobile screens.
* Uses CSS Media Queries for optimal viewing experience.

### 📄 Multi-Page Layout
* **Home:** Welcoming landing page with a hero section.
* **About:** dedicated section for personal bio.
* **Blog:** A list of articles/posts with a clean typography.
* **Contact:** Layout for social media links and contact info.

### 🎨 Modern Styling
* Clean navigation bar (Navbar).
* Consistent color palette and typography.
* Semantic HTML5 structure.

## 📥 Installation & Usage

To view this project on your local machine:

1.  **Clone the repository**
    ```bash
    git clone [https://github.com/USERNAME-GITHUB-KAMU/my-portfolio.git](https://github.com/USERNAME-GITHUB-KAMU/my-portfolio.git)
    ```

2.  **Open the folder**
    Go to the project directory.

3.  **Run the Website**
    Simply double-click `index.html` to open it in your web browser (Chrome/Edge/Firefox).
